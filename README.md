# 🍽️ Sabores Mágicos – Página Web del Restaurante

## 📋 Descripción del Proyecto
**Sabores Mágicos** es una página web desarrollada para un restaurante con el mismo nombre, cuyo objetivo es ofrecer a los clientes una **plataforma en línea moderna, informativa e interactiva**.  
A través del sitio, los usuarios pueden **explorar el menú**, **reservas**, **consultar información del restaurante** y **conectarse con sus redes sociales**.

El proyecto busca mejorar la experiencia del cliente y facilitar la interacción digital con el restaurante, reflejando su identidad y propuesta gastronómica.

---

## 🌟 Características Principales

### 🏠 1. Información del Restaurante
- Presenta la **historia**, **ubicación**, **horarios de atención** y **datos de contacto**.  
- Permite a los visitantes conocer la **propuesta gastronómica** y el concepto del restaurante.

### 📖 2. Menú en Línea
- Muestra el **menú completo** del restaurante con:
  - Descripciones detalladas  
  - Precios actualizados  
  - Fotografías atractivas de los platos  
- Navegación por **categorías** (entradas, platos principales, postres, bebidas, etc.).

### 🍽️ 3. Reservas
- Se incluye un formulario de reservas en línea que permite al cliente simular una reserva ingresando sus datos y seleccionando fecha y hora.
- Interfaz visual sencilla y clara que muestra el flujo de cómo funcionaría el sistema completo.

### 📸 4. Galería de Imágenes
- Galería visual que muestra:
  - El ambiente y las instalaciones  
  - Platos destacados  
  - Eventos especiales  
- Diseñada para generar **expectativas positivas** y atraer nuevos clientes.

### 🎨 5. Diseño Atractivo y Responsive
- Diseño **moderno, limpio y funcional**.  
- Adaptable a **diferentes dispositivos** (computadoras, tablets y smartphones).  
- Enfoque en la **usabilidad y experiencia del usuario (UX/UI)**.

### 🔗 6. Integración con Redes Sociales
- Enlaces directos a las redes del restaurante:
  - [Facebook](#)
  - [Instagram](#)
  - [Twitter](#)  
- Permite a los clientes mantenerse informados sobre promociones y eventos.

---

## 🛠️ Tecnologías Utilizadas
- **Frontend:**
  - HTML5  
  - CSS3  
  - JavaScript  
- **Diseño Responsive:** Media Queries, Flexbox, Grid  
- **Herramientas de Desarrollo:** Visual Studio Code / Sublime Text  
- **Recursos adicionales:** Imágenes, íconos y tipografías personalizadas.
